# Train To Bishan

Train To Bishan is a humorous browser game that turns the everyday Singapore MRT commute into a chaotic, interactive experience. Inspired by familiar commuter moments, the game invites players to survive the ride from the "dis"-comfort of home through seat battles, noisy passengers, unexpected encounters, and local references that make the experience instantly recognizable.

Built for the Singapore Stupid Hacks hackathon, the project was created by a team of four and won **2nd Place**.

## Project Description
At its core, Train To Bishan is a playful parody of commuting culture in Singapore. Instead of treating the daily train ride as routine, the game exaggerates real-life situations into comedic mechanics, letting players experience the frustration, unpredictability, and social awkwardness of public transport in a way that feels lighthearted and familiar.

The project was designed as a short-form interactive experience that emphasizes humor, relatability, and local flavor. Scenarios include fighting for a seat, dealing with loud passengers, reacting to crying babies, and staying balanced during the ride, creating a game that is less about winning and more about capturing a shared urban experience.

## Features
- A browser-based game experience inspired by the Singapore MRT commute.
- Humorous event-based gameplay built around familiar commuter scenarios.
- Motion-based interaction, including keeping the phone upright to mimic holding onto train handrails.
- Strong local flavor through references to civic behavior, train etiquette, and public transport culture.
